# Sorriso Perfeito - Clínica
> Site front-end desenvolvido como projeto demonstrativo, contendo páginas HTML, CSS e JavaScript.

## 📘 Sobre o Projeto
Este repositório contém um site estático que demonstra conhecimentos básicos de:
- Estruturação de páginas com HTML
- Estilização com CSS
- Interatividade com JavaScript

---
## 🛠️ Tecnologias Utilizadas
- HTML
- CSS
- JavaScript
- Imagens e recursos estáticos
- API ViaCep
- API Clim

---
## ▶️ Como Executar
1. Clone o repositório:
```bash
git clone: https://github.com/Ghost-souza006
```
2. Abra o arquivo `index.html` em seu navegador (duplo clique ou via servidor local).

Opcional — usando `Live Server` ou um servidor HTTP simples:
```bash
# com Python 3
python -m http.server 8000
# então abra http://localhost:8000
```
